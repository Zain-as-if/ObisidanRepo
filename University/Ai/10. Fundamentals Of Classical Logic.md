<h4>Propositions</h4>
Preceding argument can be explained in terms of propositional logic.
**Proposition is an expression of a fact**

Symbols, P and Q, represent propositions and the logical symbol '->' is called a propositional connective

Many systems of propositional logic have been developed, we are studying classical - i.e best established - propositional logic

In classical, taken as principle that:
**Every proposition is either true or false and not both**

Propositional logic deals with inferences governed by the meanings of propositional connectives. These expressions which operate on one or more propositions to produce another more complex proposition 

Connectives are:

| Nat. Language        | Connective        | Name        | Formula               |
| -------------------- | ----------------- | ----------- | --------------------- |
| ...and...            | $\land$           | Conjunction | (P$\land$Q)           |
| ...or...             | $\lor$            | Disjunction | (P$\lor$Q)            |
| not...               | $\neg$            | Negation    | $\neg$P               |
| if...then...         | $\rightarrow$     | Implication | (P$\rightarrow$Q)     |
| ...if and only if... | $\leftrightarrow$ | Equivalence | (P$\leftrightarrow$Q) |
Can precisely specify the well-formed formulae of propositional logic by the following (recursive) characterisation:
- Each of a set, P, of propositional constants P<sub>i</sub> is a formula
- If $\alpha$ is a formula so is $\neg\alpha$ 
- If $\alpha$ and $\beta$ are formulae so are: ($\alpha\land\beta$), ($\alpha\lor\beta$), ($\alpha\rightarrow\beta$), ($\alpha\leftrightarrow\beta$)

Schematic variables are placeholder symbols (P, Q, $\alpha$, $\beta$) that stand in for formulas, terms, expressions 

They are used to refer classes of expression sharing a common form. Thus can be used for describing patterns of inference
<h4>Inference</h4>
Inference rule characterises a pattern of valid deduction

Tells us that if we accept as true a number of propositions - called premisses - which match certain patterns, we can deduce that some further proposition is true, this is called the conclusion 

Thus we saw that from 2 propositions with the forms $\alpha\rightarrow\beta$ and $\alpha$ we can deduce $\beta$.

Inference rule can be regarded as a special type or re-write rule:
- One that preserves the truth of formulae 
- i.e. if the premisses are true so is the conclusion

<h4>Logical Arguments & Proof</h4>
Logical argument consists of a set of propositions {P<sub>1</sub>,...,P<sub>n</sub>}
called premisses and a further proposition C, the conclusion ![[Pasted image 20250518113943.png]]

Notice that speaking of an argument, not concerned with any sequence of inferences by which the conclusion is shown to follow from the premisses, such a sequence called a *proof* 

Set of inference rules constitutes a *proof system* 

Inference rules specify a class of primitive arguments which are justified by a single inference rule. All other arguments require proof by a series of inference steps

<h4>2-step proof</h4>
Suppose we know that 'If it is Tuesday or it is raining John stays in bed all day', then if we know that 'It is Tuesday' we can conclude that 'John is in bed'

Using T, R, and B to stand for the propositions involved, this conclusion could be proved in propositional logic as follows:
$$\frac{((T\land R)\rightarrow B) \cdot \frac{T}{(T\lor R)}}{B}$$
Here we have used the 'or' introduction rule followed by *modus ponens*
1. T (Premise)
2. $(T\lor R)\rightarrow B$ (Premise)
3. $T\lor R$ (From 1, by 'or' introduction)
4. B (From 2 and 3, by *implication elimination*)

<h4>Provability</h4>
To assert that C can be proved from premisses {P<sub>1</sub>,...,P<sub>n</sub>} in a proof system S, we write: $$P_{1},\dots,P_{n} \vdash_{S} C$$
This means that C can be derived from the formulae {P<sub>1</sub>,...,P<sub>n</sub>} by a series of inference rules in the proof system S

When it is clear what system is being used we may omit the subscript S on the '$\vdash$'symbol

$\alpha \vdash \beta$ - There is a formal proof of $\beta$ from $\alpha$
<h4>Validity</h4>
Argument called *valid* if its conclusion is a consequence of its premisses. Otherwise it is invalid, this needs to be made more precise, 
2 Definitions of validity:
1. An argument is valid if it is not possible for its premisses to be true and its conclusion false
2. In all possible circumstances in which the premisses are true, the conclusion is also true
To assert that the argument from premisses {P<sub>1</sub>,...,P<sub>n</sub>} to conclusion C is valid we write: $$P_{1},\dots ,P_{n} \models C$$
<u>Provability vs. Validity</u>

Provability - property of an argument which depends on the inference rules of a logical proof system 

Validity - appealing directly to the meanings of formulae and to circumstances in which they are true or false
![[Pasted image 20250518120549.png]]<h4>Relations</h4>
Smallest meaningful expression that can be represented is the proposition. However even atomic propositions (those not involving any propositional connectives) have internal logical structure

In *predicate* logic atomic propositions are analysed as consisting of a number of *individual constants* (i.e names of objects) and a *predicate*, which expresses a *relation* between the objects.

R(a,b,c) Loves(john, mary)

With many binary (2-place) relations, the relation symbol often written between operands - e.g. 4 > 3
Unary (1-place) relations are also called properties - e.g. Tall(tom)

Useful information often takes the form of statements of general properties of entities. For instance, may know that 'every dog is a mammal', such facts represented in predicate logic by means of *universal quantification* 

Given a complex formula such as $(Dog(spot)\rightarrow Mammal(spot))$, if we remove one or more instances of some individual constant we obtain an incomplete expressions $(Dog(\dots)\rightarrow Mammal(...))$, which represents a (complex) property. 

To assert that this property holds of all entities we write: 
$$\forall x[Dog(x)\rightarrow Mammal(x)]$$
in which $\forall$ is the universal quantifier symbol and x is a variable indicating which property is being quantified

E.g. 
Everything in Yorkshire is in the UK
Leeds is in Yorkshire
Therefore Leeds is in the UK 

$\forall x[InYorkshire(x)\rightarrow InUK(x)]$
InYorkshire(leeds)
InUK(leeds)

The language obtained by adding relations and quantification to propositional logic is known as **first-order** logic

Logic plays a foundational role: can be used to check consistency and other basic properties of precisely formulated theories

In computer science logic can also play this role - can be used to establish general principles of computation; can also play a rather different role as a 'component' of computer software: computers can be programmed to carry out logical deductions

![[Pasted image 20250518121728.png]]As well as being used for specifying hardware/software systems, descriptions can be used to verify properties of systems 

If $\Theta$ is a set of formulae describing a computer system and $\pi$ is a formula expressing a property of the system that we wish to ensure (e.g. $\pi$ might be the formula $\forall x[Employee(x)\rightarrow age(x)>0])$ must verify that: $$\Theta \models \pi$$ We can do this using a proof system S if we can show that: $$\Theta \models_{S} \pi$$
<h4>Logical Databases</h4>
Set of logical formulae can be regarded as a **database**

Logical database can be **queried** in a very flexible way, since for any formula $\phi$, the semantics of the logic precisely specify the conditions under $\phi$ is a consequence of the formulae in the database

Logical Database:
Likes(john, tom)
$\forall x[Likes(x,tom)\rightarrow Likes(tom,x)]$
$\forall x[Likes(x,john)\rightarrow Hates(hugo,x)]$

Query:
Hates(hugo,x)

ANS:
Hates(hugo,tom)
<h4>Logic & Intelligence</h4>
Ability to reason and draw consequences from diverse information may be regarded as fundamental to *intelligence* 

As principal intention in constructing a logical language is to precisely specify correct modes of reasoning, a logical system (i.e. a logical language plus some proof system) might in itself be regarded as a form of *Artificial intelligence*
