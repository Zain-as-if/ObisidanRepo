<h4>Notation</h4>
$\mathbb{Z}$ = Set of integers {...,-2,-1,0,1,2,...}
$\mathbb{N}$ = Set of natural numbers {>=1}

Sequence of objects is list of these objects denoted using parentheses e.g. (4,2,3). Finite sequences often called k-tuples, containing k elements. 

String is sequence of symbols. Set of symbols from which elements of string come from is called alphabet. Only requirement is that alphabet is non-empty and finite set.
E.g.
$\sum_{1} = \{0,1\}$
$\sum_{2}=\{a,b,c,d,...,z\}$ 

String over an alphabet is finite sequence of symbols from alphabet usually written next to each other. E.g. using $\sum_{1}=\{0,1\}$ then 01010 would be a string over $\sum_{1}$. If w is string over $\sum$ then length of w denoted |w| = number of symbols in sequence. String of length zero called empty string, denoted $\epsilon$. If w has length n can write $$w=w_{1},w_{2},\dots,w_{n}$$ where $w_{i} \in \sum$ for 1<=i<=n. Reverse of a string over an alphabet is string in opposite order. String is substring of w if it appears consecutively within w. Call x the prefix of a word w if w = xy for some string y. Concatenation of two strings $x=x_{1},\dots x_{n}, y=y_{1},\dots y_{m}$, denoted xy, string $w=x_{1}\dots x_{n}y_{1}\dots y_{m}$. Kleene star is unary operator that constructs a set of elements given a set of elements. If $\sum$ is finite alphabet then $\sum^*$ is set of all finite length strings over that alphabet. If $\sum$ is finite, $\sum^*$ is countably infinite.

<h4>Finite State Automata</h4>
Finite state automaton is model of computation with extremely limited amount of memory not expandable during run time.
E.g.
In case of train barriers and runway, barrier controller (uses sensors) is in three states: "barriers closed", "barriers open", "warning of oncoming vehicle" (when train oncoming and vehicle detected). 
Controller will transition between states based on what the sensors detect. Because of simple nature of such controls, make them ideal for safety critical systems as it is possible to reason about their correct operation. 
<h4>Deterministic Finite State Automata (DFA)</h4>
Has finite set of states, behaviour is deterministic which means at each stage of computation the next state of the machine is and will be determined by only the **current state**, **symbol being read** and the **transition function** - no guessing required. 

Deterministic Finite Automaton is a 5-tuple (Q,$\sum$,$\delta$,$q_{0}$,F) where:
1. Q - finite set called **states**
2. $\sum$ - finite set called **alphabet**
3. $\delta:Q\cdot \sum\to Q$ - **transition function**
4. $q_{0}\in Q$ - **start state**
5. $F\subseteq Q$ - set of **accepting states**

One of states from Q designated as **starting** state. Starting state is the state the machine is in when the machine starts processing the input string. Subset of set Q are designated as accepting states (F). If automaton reaches end of input string whilst in accepting state then automaton will output accept. Strings which automata can process contain only symbols from the finite alphabet $\sum$ 

Transition function defines the next state the automaton will be in when it reads the next symbol from input string. Pay close attention to the domain and codomain (output) of transition function. Domain is cartesian product of set of states (Q) and alphabet ($\sum$) - that is for each pair of state and symbol, the transition function defines what is the next state. Codomain of transition function is set of states Q. 

E.g.
Let $M=(Q,\sum,\delta,q_{0},F)$ be a finite automaton, let $w=w_{1}\dots w_{n}$ be string where $w_{i}\in \sum$ for $1\leq i\leq n$. Automaton M accepts w if sequence of states $r_{0},\dots,r_{n}\in Q$ exists such that:
1. $r_{0}=q_{0}$ : sequence of state must be start state
2. $\delta(r_{i},w_{i+1})=r_{i+1}$ for $0\leq i<n$ : sequence of states progresses in accordance with transition function
3. $r_{n}\in F$ : final state is accepting state
We can say automaton M recognises a language A if $A=\{w\in \sum^*|M\text{ accepts }w\}$
If deterministic automaton doesn't accept a given string then machine rejects string and string is not part of the language recognised by the automaton
