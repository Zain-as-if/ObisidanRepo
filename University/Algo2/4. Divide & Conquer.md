Divide & Conquer technique leads to recursive algorithms. This paradigm involves three steps at each level of the recursion:
- **Divide**, the current instance into a number of sub-instances of the same problem but smaller in size
- **Conquer**, the sub-instances by solving them recursively, if an instance is small enough, solve it directly
- **Combine**, the solutions to the sub-instances into a solution for the original instance
Divide conquer algorithms recursive
E.g. Binary Search, Merge Sort, Quick Sort

Running time of divide-and-conquer algorithm can be bounded by a function $T:\mathbb{N}\rightarrow\mathbb{N}$ given by a recurrence

Each recurrence consists of **initial conditions** T(n) = c<sub>n</sub> for small n and a **recursive equation** that describes T(n) in terms of n and T(m) for some m < n

E.g. Of recurrences:
- Fibonacci Sequence:
	- F(0) = 0
	- F(1) = 1 
	- F(n) = F(n-1) + F(n-2) for all n > 1
- Towers Of Hanoi:
	- T(0) = 0
	- T(n) = 2 $\cdot$ T(n-1) + 1 for all n > 0
- Quick Sort
	- T(1) = 0
	- T(n) = n + T(n-1) for all n > 1
Instead of implicit definition we want explicit growth rate
E.g.
- Fibonacci Numbers: $F(n)=O((\frac{1}{2}(1+\sqrt{5}))^n)$
- Towers Of Hanoi: $T(n)=O(2^n)$ 
- Quick Sort: $T(n)=O(2^n)$
Methods:
1. **Direct Method**, also known as substitution method always applies, sometimes tricky
2. **Guessing Solution**, applies to recurrences in form: $$T(n)=a_{1}T(n-1)+a_{2}T(n-2)+a_{3}T(n-3)+\dots+a_{k}T(n-k)$$
3. **Master Method**, applies to recurrences in form:$$T(n)=aT(\frac{n}{b})+f(n)$$
<h4>Direct Method</h4>
We solve the quick sort recurrence by substitutions:$$\begin{align*}T(n)&=n+T(n-1)\\&=n+(n-1)+T(n-2)\\&=n+(n-1)+(n-2)+T(n-3)\\&=n+(n-1)+(n-2)+\dots+2+T(1)\\&=n+(n-1)+(n-2)+\dots+2+1+T(0)\\&=n+(n-1)+(n-2)+\dots+2+1+0\\&=\frac{1}{2}n(n+1)\\&=O(n^2)
\end{align*}$$
Using T(n-1) = n-1 + T(n-2)

<h4>Guessing Solution</h4>
We guess F(n) = c<sup>n</sup> is (for a suitable constant c) the solution to the Fibonacci recurrence: $F(n) = F(n-1) + F(n-2)$
$$\begin{align*}c^n&=c^{n-1}+c^{n-2}\\c^2&=c+1\\c^2-c-1&=0\\c_{1,2}&=\frac{1}{2}\pm\sqrt{(\frac{1}{2})^2+1}\\c_{1}&=\frac{1}{2}(1+\sqrt{5})\\c_{2}&=\frac{1}{2}(1-\sqrt{5})\end{align*}$$
Since n > 1 for Fibonacci, Choose c1 

We now guess $F(n)=a\cdot c^n_{1}+b\cdot c^n_{2}$ is solution for suitable constants a and b and use the initial conditions to find a and b $$\begin{align*}0&=a+b \qquad\qquad &n=0\\1&=\frac{a}{2}(1+\sqrt{5})+\frac{b}{2}(1-\sqrt{5}) \qquad\qquad &n=1\end{align*}$$
which implies: $$\begin{align*}a&=+\frac{1}{5}\sqrt{5}\\b&=-\frac{1}{5}\sqrt{5}\end{align*}$$
<u>Proof By Induction</u>
Let $G(n)=a\cdot c^n_{1}+b\cdot c^n_{2}$
**Base Case**: Already know F(0) = G(0) and F(1) = G(1)
**Inductive Step**: $$\begin{align*}F(n)&=F(n-1)+F(n-2)&\text{recursive equation}\\&=G(n-1)+G(n-2)&\text{induction hypothesis}\\&=ac_{1}^{n-1}+bc_{2}^{n-1}+ac_{1}^{n-2}+bc_{2}^{n-2}&\text{definition of G}\\&=ac_{1}^{n-2}(c_{1}+1)+bc_{2}^{n-2}(c_{2}+1)\\&=ac_{1}^n+bc_{2}^n&c_{1}^2=c_{1}+1;c_{2}^2=c_{2}+1\\&=G(n)&\text{definition of G}\end{align*}$$
We proved: $$F(n)=\frac{1}{5}\sqrt{5}[(\frac{1+\sqrt{5}}{2})^n-(\frac{1-\sqrt{5}}{2})^n]$$
which means: $F(n)=O(c_{1}^n)$

Method applies to recursive equations of type $T(n)=f(n)+\sum^k_{i=1}a_{i}T(n-i)$, where k > 0 is an integer, and so are the coefficients $a_{i}\geq 0$ for i = 1,2,...,k 
- Consider function $T'$ that fulfils recursive equation $T'(n)=\sum^k_{i=1}a_{i}T'(n-i)$
- Guess $T'(n)=c^n$ and substitute this into recursive equation for $T'$
- Compute the largest root $c_{1}$ of resulting polynomial equation or approximate it, for instance by Newton's method, Real root $c_{1}>1$ exists if $\sum^k_{i=1}a_{i}>1$ 
- Prove $T(n)=O(c_{1}^n\cdot f(n))$ by induction
In case you use approximation of $c_{1}$ and f(n) is bounded from above by a polynomial in n, note that $c_{1}^n\cdot f(n)=O((c_{1}+\epsilon)^n)$ holds for all $\epsilon$ > 0, That is, you prove $T(n)=O((c_{1}+\epsilon)^n)$ by induction
<h4>Master Method</h4>
Master method applies to recurrences of form: $$T(n)=a\cdot T(\frac{n}{b})+f(n)$$
where a>=1 and b>1 are constants and f(n) > 0 for almost all n

Theorem:
Let a, b, f, and T as above
T(n) can be bounded asymptotically as follows:
- If $f(n)=O(n^{\log_{b}a-\epsilon})$ for some constant $\epsilon$ > 0, then $T(n)=O(n^{\log_{b}a})$
- If $f(n)=O(n^{\log_{b}a})$ then $T(n)=O(n^{\log_{b}a}\log n)$ 
- If $n^{\log_{b}a+\epsilon}=O(f(n))$ for some constant $\epsilon>0$ and if $af(\frac{n}{b})\leq cf(n)$ for some constant c<1 and almost all n, then $T(n)=O(f(n))$

Theorem (New Master Theorem)
Let $T:\mathbb{R}_{\geq 1}\rightarrow\mathbb{R}_{>0}$ be a function such that:$$T(x) = \begin{cases}h(x) &\text{for }1\leq x\leq x_{0}\\a\cdot T(\frac{x}{b})+f(x)&\text{for }x>x_{0}\end{cases}$$
Where:
1. $a>0, b>1$ and $x_{0}\geq b$ are constants
2. $d_{1}\leq h(x)\leq d_{2}$ for constants $d_{1}>0$ and $d_{2}>d_{1}$ and all x with $1\leq x\leq x_{0}$
3. f is a non-negative function such that constants $c_{1}>0$ and $c_{2}>c_{1}$ exist with $c_{1}f(x)\leq f(u)\leq c_{2}f(x)$ for all $x>x_{0}$ and u with $\frac{x}{b}\leq u\leq x$ 
4. $I(x_{0})<\infty$ where $I(x)=\int^x_{1}\frac{f(u)}{u^{p+1}}du$ and $p=\log_{b}a$
Then $T(x)=\theta(x^p(1+I(x)))$ ![[Pasted image 20250522215617.png]]
